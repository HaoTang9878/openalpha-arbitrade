OpenAlpha 暴露约 **50 个 REST 端点**，涵盖状态、配置、扫描、机会检测、交易执行、策略调度、回测、用户认证、AI 建议。所有写操作（POST / PUT / DELETE）都需要 `Authorization: Bearer ${ARBITRAGE_API_TOKEN}`。

## 健康与系统

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| `GET` | `/` | HTML 首页（仪表盘 SPA） | 公开 |
| `GET` | `/bots` | 机器人监控页 | 公开 |
| `GET` | `/backtest` | 回测页面 | 公开 |
| `GET` | `/heatmap` | 价差热力图 | 公开 |
| `GET` | `/reports` | 每日报告页 | 公开 |
| `GET` | `/settings` | 设置页 | 公开 |
| `GET` | `/api/status` | 系统运行状态（模式 / uptime / version） | 公开 |
| `GET` | `/metrics` | Prometheus 指标 | 公开 |

## 配置管理

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| `GET` | `/api/config` | 读取当前生效配置 | 公开 |
| `PUT` | `/api/config` | 修改配置（合并语义） | Token |
| `GET` | `/api/symbols` | 读取监控交易对列表 | 公开 |
| `PUT` | `/api/symbols` | 覆盖更新监控交易对 | Token |
| `GET` | `/api/symbols/categories` | 币种分类表（主流 / DeFi / L2 / AI / RWA / Meme） | 公开 |

### 修改配置示例

```bash
curl -X PUT http://127.0.0.1:8070/api/config \
  -H "Authorization: Bearer ${ARBITRAGE_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "min_profitability": 0.0015,
    "order_amount": 0.02,
    "scan_interval": 5,
    "paper_trade": true
  }'
```

### `/api/test-order` 请求示例

```bash
curl -X POST http://127.0.0.1:8070/api/test-order \
  -H "Authorization: Bearer ${ARBITRAGE_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "exchange": "binance",
    "symbol": "BTC/USDT",
    "side": "buy",
    "amount": 0.001
  }'
```

返回 `{"status": "simulated", ...}`，实盘下单逻辑接入后此处返回真实订单 ID。

## WebSocket

连接 `ws://localhost:8070/ws`，订阅实时推送：

| 消息类型 | payload 字段 | 说明 |
|----------|--------------|------|
| `prices` | `{exchange, symbol, bid, ask, last, ts}` | 价格更新 |
| `opportunities` | `{buy_exchange, sell_exchange, symbol, profit_bps, ...}` | 套利机会 |
| `trade` | `{symbol, profit, ...}` | 交易结果 |
| `status` | `{running, mode, uptime}` | 系统状态 |
| `logs` | `{level, message, timestamp}` | WARNING+ 级别日志 |

前端默认每条都订阅，可以用 `?types=prices,opportunities` 过滤。

## 错误码

| 状态码 | 含义 |
|--------|------|
| `200` | 成功 |
| `401` | 缺少或无效的 Bearer Token（写操作） |
| `403` | CORS / IP 限流拒绝 |
| `404` | 端点不存在 |
| `422` | 请求参数校验失败（如 `tranche_count > 20`） |
| `429` | IP 限流（默认 60 req/min） |
| `500` | 服务内部异常（栈写入日志 + JSONL） |
| `503` | runtime_state / event_store 尚未初始化 |

<Tip>
  所有 `5xx` 响应同时会写入 `data/events.jsonl`（`type=error`），运维可以通过事件流回溯。
</Tip>
